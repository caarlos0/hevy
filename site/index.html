Human-readable when you are exploring. Machine-readable JSON when a script or agent needs the same data. One CLI, no translation layer.

Predictable enough
for the machines.

Machine-readable JSON goes to stdout. Human-readable errors go to stderr; JSON dry-run validation stays on stdout. Failures return a non-zero exit, giving scripts and agents a contract instead of decorated terminal output.

STDOUTMACHINE JSON→ pipe it
STDERRHUMAN ERRORS→ catch it
EXITNON-ZERO→ branch on it
