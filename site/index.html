02 / COMPOSE

Use the tools already in your hands.

Read JSON from files or stdin. Edit in $VISUAL, $EDITOR, or round-trip a live routine through jq.

03 / VALIDATE

Test the payload.
Not your luck.

--dry-run checks required fields, types, and dates before a create or edit request mutates your account.

$hevy workouts create --file workout.json --dry-run --json
✓
PAYLOAD VALID{ "ok": true, "resource": "workout" }
NO WRITE REQUEST

File-backed dry runs validate locally and can run without an API key.

Predictable enough
for the machines.

Raw API responses go to stdout. Errors go to stderr and return a non-zero exit. Your scripts and agents get a contract, not decorated terminal output.
