# Hevy CLI landing page

- Mode: Persuade
- Audience: lifters who work in terminals, developers, automation-minded athletes, and agent builders.
- Job: understand what the CLI unlocks, verify that it fits shell and agent workflows, then install it or inspect the source.
- Primary action: install `@caarlos0/hevy`; secondary action: open the upstream GitHub repository.
- Proof: real commands and verified behavior from README, source, tests, API docs, and release artifacts. Interface data is labeled illustrative.
- Direction: a strength-programming ledger turned into a live command surface. Ruled rows, red training marks, terminal output, workout sheets, and progressive training data share one visual grammar.
- Memorable moment: the hero terminal overlaps a paper workout sheet, showing the shell and training log as two views of the same data.
- Constraints: clearly community-built, no official affiliation, no copied proprietary UI, no invented usage claims, responsive, keyboard accessible, and reduced-motion safe.
